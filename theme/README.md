# Bounce Back Shopify Theme

A customized Shopify Online Store 2.0 theme based on Shopify Dawn, styled for the Bounce Back activewear brand.

## Included

- Premium dark/light visual system based on the Return Arc CI
- Responsive homepage sections, collections, product, cart, blog, search, and standard Shopify templates
- Editable LINE OA, support information, and PromptPay QR settings
- Product stock visibility, care guidance, exchange guidance, and LINE sales support
- Purpose-built page templates: `page.care`, `page.exchange`, and `page.bounce-contact`

## Required store setup

1. Create navigation menu `main-menu` and collections with handles `shirts`, `pants`, and `accessories`.
2. In Theme settings, replace the LINE OA placeholder and upload the final PromptPay QR.
3. Create pages and assign the included alternate templates.
4. Configure a manual payment method in Shopify Admin for the QR/bank-transfer workflow.
5. Upload the final logo and campaign/product photography through Shopify Theme Editor.
